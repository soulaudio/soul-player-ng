# Rune Head Implementation Plan (`app/rune`)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Build a native-Rust **Rune** UI head (`app/rune`) over `soul-player-host`'s `PlayerHandle` — a single-screen player mirroring the old `soul-player` sidebar-centric layout — so we can compare it head-to-head with the Tauri+Svelte head.

**Architecture:** `app/rune` is a new nested-workspace binary that embeds `PlayerHandle` directly (no IPC). Rune owns the event loop; our audio backend's `Tick`/`Queue` events are pushed onto the UI thread via `AppHandle::update` from the host's `subscribe` callback. The view is a retained, diffed `col()/row()/el()/text()` tree; the library list is virtualized; seek/volume are hand-built sliders; cover art loads encoded bytes straight into Rune's `ImageCache`.

**Tech Stack:** Rust (edition 2024), `rune` + `rune-kit` (git, pinned dev rev), `soul-player-host` (path), wgpu (Vulkan/DX12 on Windows).

**Scope:** Single "Tracks" screen with the old app's layout — left sidebar (nav label → upcoming Queue → Player Panel: cover/title/artist, seek bar, transport, volume) + main virtualized track list, click-to-play. Follow-system theming (Day light + Night dark, exact old-app palettes). **Out:** multi-page nav, albums/artists/playlist grids, settings, search, window chrome, mobile/collapsed layouts, format badges, heart/playlists.

```rust
#![forbid(unsafe_code)]

use rune::{App, AppSpec, Cx, El, Tx, col, text};
use soul_player_host::{Command, Event, PlayerHandle, RepeatMode, TrackView};

struct State {
    host: PlayerHandle,
    library: Vec<TrackView>,
    now_playing_id: Option<u32>,
    position_secs: f64,
    duration_secs: f64,
    playing: bool,
    volume: f32,
    shuffle: bool,
    repeat: RepeatMode,
    up_next: Vec<u32>,
    context_pos: u32,
    context_len: u32,
}

impl State {
    fn new(host: PlayerHandle) -> Self {
        let library = host.views();
        Self {
            host,
            library,
            now_playing_id: None,
            position_secs: 0.0,
            duration_secs: 0.0,
            playing: false,
            volume: 1.0,
            shuffle: false,
            repeat: RepeatMode::Off,
            up_next: Vec::new(),
            context_pos: 0,
            context_len: 0,
        }
    }

    /// Fold one backend event into the UI state. Mirrors the Svelte store's
    /// `bindPlayerEvents` (app/tauri/src/lib/store.svelte.ts).
    fn apply(&mut self, ev: &Event) {
        match ev {
            Event::Tick(t) => {
                self.now_playing_id = t.now_playing_id;
                self.position_secs = t.position_secs;
                self.duration_secs = t.duration_secs.unwrap_or(0.0);
                self.playing = matches!(t.state, soul_player_host::PlayState::Playing);
                self.volume = t.volume;
                self.shuffle = t.shuffle;
                self.repeat = t.repeat;
            }
            Event::Queue(q) => {
                self.up_next = q.up_next_ids.clone();
                self.context_pos = q.context_pos;
                self.context_len = q.context_len;
            }
        }
    }

    fn track(&self, id: u32) -> Option<&TrackView> {
        self.library.iter().find(|t| t.id == id)
    }
}

fn view(s: &State, _cx: &mut Cx<State>) -> El {
    let now = s
        .now_playing_id
        .and_then(|id| s.track(id))
        .and_then(|t| t.title.clone())
        .unwrap_or_else(|| "—".to_string());
    col()
        .padding(24.0)
        .gap(8.0)
        .child(text(format!("{} tracks", s.library.len())))
        .child(text(format!("now playing: {now}")))
        .child(text(if s.playing { "▶ playing" } else { "⏸ paused" }))
}

fn main() -> anyhow::Result<()> {
    let host = PlayerHandle::new();
    host.autoload_from_env()?; // SOUL_PLAYER_FOLDER=<dir> to load a library

    let spec = AppSpec::<State> {
        ..AppSpec::new("Soul Player (Rune)", (1100.0, 720.0), || unreachable!("init overridden"), view)
    };
    let init_host = host.clone();
    let app = App::new(spec).init(move || State::new(init_host.clone()));
    let ah = app.handle();
    host.subscribe(move |ev: Event| {
        ah.update(move |s: &mut State, tx: &mut Tx| {
            s.apply(&ev);
            tx.instant(); // don't animate fast-moving numeric fields
        });
    });
    app.run();
    Ok(())
}
```
Notes for the implementer: the exact `App::new(...).init(...)` / `.handle()` / `.run()` surface is in cheat-sheet §2 and `examples/live-values`; if `init` requires the `AppSpec.init` field to be a real `fn` even when overridden, give it `State::default`-style stub or the builder's documented no-op — follow the example. `tx.instant()` per cheat-sheet §5(c); if named differently, match the source.

```rust
//! Main-area track list: one row per library track, click to play.
#![forbid(unsafe_code)]

use rune::{El, col, row, text};
use soul_player_host::Command;

use crate::State;
use crate::theme::Palette;

fn fmt_dur(secs: f64) -> String {
    let s = secs.max(0.0) as u64;
    format!("{}:{:02}", s / 60, s % 60)
}

fn track_row(s: &State, p: &Palette, index: usize) -> El {
    let t = &s.library[index];
    let playing = s.now_playing_id == Some(t.id);
    let ids: Vec<u32> = s.library.iter().map(|x| x.id).collect();
    let start = index as u32;
    row()
        .key(format!("track-{}", t.id))
        .gap(12.0)
        .padding(8.0)
        .child(text(format!("{}", index + 1)).color(p.text_secondary).w(28.0))
        .child(text(t.title.clone().unwrap_or_else(|| "Unknown".into())).color(if playing { p.accent } else { p.fg }).grow(1.0))
        .child(text(t.artist.clone().unwrap_or_default()).color(p.text_secondary).grow(1.0))
        .child(text(t.album.clone().unwrap_or_default()).color(p.text_secondary).grow(1.0))
        .child(text(fmt_dur(t.duration_secs)).color(p.text_secondary).w(56.0))
        .on_press(move |st: &mut State| st.host.send(Command::PlayContext { ids: ids.clone(), start }))
}

pub fn track_list(s: &State, p: &Palette) -> El {
    let mut list = col().gap(2.0);
    for i in 0..s.library.len() {
        list = list.child(track_row(s, p, i));
    }
    // Wrap in the scroll viewport (confirm ScrollSpec fields against examples/todo).
    list.scroll(Default::default())
}
```
Adjust `.w`/`.grow`/`.scroll`/`.on_press` to the real signatures. If a closure capturing `ids` per row is too heavy, hoist the id list into `State` once and index it.
